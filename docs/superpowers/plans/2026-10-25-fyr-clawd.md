# Fyr-Clawd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small Clawd lives at the lighthouse in Ghostty's sky (a day routine through the tower, surfing, a night of stargazing, a hammock, lantern duty), a UFO abducts him now and then, and the lighthouse stands three times larger on a stage strip of right padding that terminal text never reaches.

**Architecture:** Everything he does is GLSL, a pure function of `iTime` plus baked scene constants. The shader schedules the abduction itself (like `shootingStars`), because events baked by the session play from an unknown phase. TypeScript only bakes the new constants (`STAGE_PX`, `KEEPER_ASLEEP`, `KEEPER_FORCE`) and writes the padding line into Ghostty's config through `/solar ghostty`.

**Tech Stack:** TypeScript (Claude Code mod engine, `claude plugin test`), GLSL (Ghostty 1.3 custom shader; preview in WebGL2 via `tools/preview/run.sh shader`).

**Spec:** `docs/superpowers/specs/2026-10-25-fyr-clawd-design.md` (Swedish). Read it first: the routine, the anti-goals and the decisions are there.

## Global Constraints

- Draw only in the risograph inks (`INK_*` constants from `INKS`), screened with `screen(...)`, the key plate off register with `ink(...)` as `beacon()` and `dolphin()` do. No flat colours outside the palette.
- Any moment of `iTime` must look right as a still frame: the sky is not made to animate more for him (spec, "Beslut: himlen animerar inte mer"). `animationOf` and `livelyAt` are unchanged, apart from forced previews counting as events, as they already do.
- Lighthouse scale: `s = 3.0 * 0.65 * u`. Position: `x = STAGE_PX > 0.0 ? iResolution.x - 0.5 * STAGE_PX : 0.88 * iResolution.x`. Its foot stays on the horizon `ARC.w * iResolution.y`.
- Stage margin: `STAGE_PT = 240`, written as `window-padding-x = <left>,240` where `<left>` is the first number of the person's own `window-padding-x` line if they have one, else `2`. `STAGE_PX = STAGE_PT × backingScaleFactor` on macOS, `STAGE_PT × 1` on Linux, `0` where unknown (iTerm2, previews without `--stage`).
- Fyr-Clawd's cell size: `max(1.0, floor(0.09 * s))` px; his shape is the band's logo grid (`clawdRows` in `hooks/clawd.ts`: head, face, arms, legs, 6 × 4), in `CORAL` (orange over cream) with indigo eyes.
- Everything new early-exits outside a box around the lighthouse (±`4.0 * s` horizontally, from `deck - 3.0 * s` to `foot + 1.0 * s`, widened upward for the UFO), as `beacon()` does.
- User-facing words in English (the band and `/solar` speak English since `44fedae`); comments in the existing voice.
- Every function that takes `$` is a top-level function in `hooks/register.tsx` or `hooks/ghostty.ts`, never a closure.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; the repo's local git identity.
- Verify each task: `claude plugin test .` (all pass), `npx -y -p typescript@5.6.3 tsc -p .` (clean), and for GLSL changes `tools/preview/run.sh shader …` compiles (no `FAIL` in the PNG) and the PNG is looked at.
